# FAUN.dev brand logos

| File | Use |
|---|---|
| `faun-logo-white.png` | Raised paw logo. Put it on a blue background (covers, blue bands). |
| `faun-logo-blue-disc.png` | The same logo on a blue disc (#007bff). Use it on white pages (page headers). |

In HTML you can also show `faun-logo-white.png` with `background: #007bff; border-radius: 50%;` to get the blue disc.
The old flat blue paw (`logo-flat-*.png`) is retired. Do not use it.
